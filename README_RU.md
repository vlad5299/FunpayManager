# FunPay Manager — первая версия

Это безопасная стартовая версия Telegram-панели. Она:
- отвечает только владельцу (ADMIN_ID);
- поддерживает `/start`, `/status`, `/test`, `/help`;
- не просит присылать токен в чат;
- пока **не подключается к FunPay** и не отправляет сообщения покупателям.

## Переменные окружения

В облачном хостинге добавьте:
- `TELEGRAM_BOT_TOKEN` — токен, выданный BotFather;
- `ADMIN_ID` — ваш числовой Telegram ID.

Не добавляйте токен в исходный код, GitHub или переписку. Если токен случайно раскрыт, перевыпустите его через BotFather.

## Запуск

```bash
pip install -r requirements.txt
python bot.py
```

На Railway создайте сервис из этого проекта и задайте две переменные окружения выше. Запускайте как один постоянно работающий worker. Не запускайте одновременно несколько копий с одним токеном.

## Следующий этап

До интеграции с FunPay нужно проверить, какой официальный/разрешённый платформой способ доступа доступен для вашего аккаунта. Не передавайте пароль, cookies или коды входа сторонним ботам и не вставляйте их в переписку.
